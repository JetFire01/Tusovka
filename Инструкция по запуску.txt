Tusovka — Инструкция по запуску
================================

Есть два сценария:


1. ЗАПУСТИТЬ СВОЙ ЭКЗЕМПЛЯР (ОТДЕЛЬНАЯ БД)
------------------------------------------

Нужен Node.js 18+ установленный на компьютере.

git clone <ссылка на репозиторий>
cd tusovka
npm install
npm run dev

Откроется на http://localhost:3000. БД создастся автоматически.


2. ПОДКЛЮЧИТЬСЯ К СЕРВЕРУ ОРГАНИЗАТОРА (ОБЩАЯ БД)
--------------------------------------------------

Это основной сценарий — один сервер, все заходят на него.

Шаг 1: Организатор запускает сервер у себя (npm run dev).

Шаг 2: Узнать IP в локальной сети:
- macOS: ifconfig | grep "inet " | grep -v 127.0.0.1
- Или посмотри в Системных настройках → Wi-Fi → IP-адрес

Сервер при запуске сам показывает IP:
  - Network: http://192.168.1.40:3000

Шаг 3: Друзья в той же Wi-Fi сети открывают в браузере
(в том числе на телефоне):
  http://192.168.1.40:3000
(подставив IP организатора)


3. ДОСТУП ИЗ ДРУГОЙ СЕТИ / ИЗ ИНТЕРНЕТА
-----------------------------------------

Если друзья не в твоей Wi-Fi, есть варианты:

- Tailscale (самый простой) — установи на свой компьютер и на устройства
  друзей. Бесплатно, работает как VPN. Друзья заходят по Tailscale IP.

- Cloudflare Tunnel — бесплатный туннель, даёт публичный URL
  без проброса портов.

- Проброс портов на роутере — открыть порт 3000 наружу.
  Друзья заходят по твоему внешнему IP.

Самый беспроблемный вариант — Tailscale. Установка за 2 минуты,
работает на телефонах тоже.
